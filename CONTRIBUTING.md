# Contributing

1. Fork and clone the repository.
2. Install Node.js 20 or newer and run `npm install` (there are no runtime dependencies).
3. Create a focused branch such as `feat/calendar-export`.
4. Run `npm test`, `npm run lint`, `npm run build`, and `npm run seo`.
5. Open a pull request describing the user problem, design trade-offs, and policy impact.

Please include tests for scheduling rules and keep examples honest about what is implemented. Never include API keys, cookies, OAuth secrets, or session tokens.
